# collider-db-team09
Particle Collider Event and Decay Database (CSE311.4, Team 09)

MySQL implementation of our ERD and schema. Event data comes from the CMS dimuon dataset (Run2010B) on the CERN Open Data Portal (opendata.cern.ch). Detector, particle and decay tables were entered from public CERN and PDG information.

Files:
- collider_db.sql: schema, data and triggers
- dimuon.csv: original source data
